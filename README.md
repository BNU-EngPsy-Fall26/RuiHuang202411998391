# 冲突与刻度：复现 + 改进

两个经典注意实验的网页复现，每个实验都加入了一个原版之外的新条件：

- **01 Stroop 颜色命名**：整合显示 vs **分离显示**（词与颜色分成两个客体）
- **02 Cleveland–McGill 比例判断**：无刻度 vs **有刻度**（25/50/75）

被试可以只做一个实验，也可以两个都做（用同一个匿名编号）。数据自动上传到课程收数接口（`/hw2`），结果页可看全体匿名汇总。

- **项目码**：`NLTYFA`（见 `js/config.js` 第 10 行；下载密钥不在仓库里）
- **多位被试**：同一台电脑连续做时，结束页点「下一位被试（换编号）」，或用链接 `?pid=P01` 指定编号；否则数据会记在同一个人名下
- **在线地址**：（GitHub Pages 地址，部署后填在这里）
- **本地运行**：双击 `index.html`（Chrome / Edge），无需构建、无需服务器、无需联网也能做实验（上传需要联网）

> 课程要求：代码提交到课程 GitHub Organization；README 写明项目码与运行方法；助教 clone 后双击 `index.html` 能直接运行并成功上传。

## 1. 研究问题与设计总览

| | 实验一 | 实验二 |
|---|---|---|
| 范式 | Stroop 颜色命名（Stroop, 1935） | 比例判断（Cleveland & McGill, 1984） |

## 2. 实验一：Stroop 颜色命名

### 2.1 出处与原始结果

Stroop, J. R. (1935). Studies of interference in serial verbal reactions. *Journal of Experimental Psychology, 18*, 643–662.

原文 Experiment 2（口头命名、卡片式、100 项）：

| 条件 | 每 100 项用时 |
|---|---|
| 命名色块（NC） | 63.3 s |
| 命名字义与墨色冲突的词（NCWd） | 110.3 s |
| 干扰 | **+47.0 s（+74.3%）**，即约 470 ms/项 |

本实验把口头命名改为四色按键（键位见 2.2），并逐试次计时。因此绝对量级不能与原文直接相比（见 6.3），比较的是**方向、比值与改进条件的相对变化**。

### 2.2 条件与试次

- 2（一致性：一致 / 不一致）× 2（显示：整合 / 分离），被试内，每格 20 试次，共 80。
- **整合**：经典 Stroop，颜色直接是词的墨色。
- **分离**：词用中性灰 `#B0A795` 呈现（对比度约 7.8:1，且位于注视点、字号 104 px），颜色由词上方 46×46 px 的独立色块承载，被试判断**色块**的颜色。
- 区组：两个区组各 40 试次（一个整合、一个分离）。**区组顺序由匿名编号的哈希值决定**（与键位映射用不同的哈希，避免两者绑定）。
- 试次内：3-2-1 准备 → 注视 500 ms → 刺激（≤2000 ms）→ 空屏 500 ms（+0–100 ms 抖动）。
- 练习 12 次，带对错反馈；正式试次无反馈。
- 每块内四种墨色各 10 次、一致/不一致各 20 次；不一致试次的词义从其余三色中轮换。

### 2.3 试次流程与计时

每个区组开始前先 3-2-1 准备，然后严格按下面的循环走（练习与正式一致，只是练习带反馈）：

```
3-2-1 准备
   ↓
注视点（十字，500 ms）          ← 被试把眼睛放回屏幕中央
   ↓
刺激（颜色词 / 色块，≤ 2000 ms）  ← 按键即进入下一段；到 2000 ms 未反应则记为超时
   ↓
空屏（500 ms + 0–100 ms 随机抖动）← 清屏，避免连续刺激重叠、减少节奏预期
   ↓
回到注视点，循环
```

| 时段 | 取值 | 依据 |
|---|---|---|
| 注视点 | 500 ms | 计算机化 Stroop 的常用值：足够把注视点收回中央，又不至于让被试走神 |
| 反应窗口 | 2000 ms | 四选一手动 Stroop 的正确 RT 中位数通常在 600–900 ms；2 s 覆盖绝大多数正确反应，同时给"卡住"的试次一个明确的结束点 |
| 空屏 | 500 ms + 0–100 ms 抖动 | 让连续两个刺激在时间上分开；抖动避免被试按固定节奏预判 |
| 练习反馈 | 650 ms | 只在练习出现；正式试次无反馈 |

计时实现：

- `performance.now()`；起点是刺激在 `requestAnimationFrame` 回调里实际绘制的那一帧，终点是 `keydown`；
- 反应 < 150 ms 记为抢按、> 2000 ms 记为超时；两者都不进入 RT 分析（但会计数并报告）；
- 超时试次不会"卡住"流程：到点自动结束、记 `timeout=1`，进入空屏和下一试次。

> 这些值是**收数前的先验设定**；如果被试的实际 RT 分布显示超过 1% 的正确反应撞到 2000 ms 上限，会在正式收数前把窗口放宽到 2500 ms（改动会记录在 git 里）。参考文献：Stroop (1935) 的原始范式与 MacLeod (1991) 的综述；具体毫秒值是计算机化实现中的常见做法，而不是某一篇论文的唯一规定。

### 2.4 指导语（要点）

> 判断字呈现的**颜色**，不是字的意思；键位以屏幕上方的提示为准（红/黄/蓝/绿对应两套镜像映射之一）；又快又准。第一段颜色涂在字上，第二段颜色在字上方的方块里——两段都判断颜色。

### 2.5 改进：显示分离

- **理论**：Stroop 干扰至少有两个来源——词义的自动激活（语义冲突），以及"词与颜色属于同一个客体"的整体编码（知觉整合）。若把颜色从词身上剥离、变成独立客体后干扰明显下降，说明整体编码是重要来源；若干扰仍然存在，则说明语义冲突可以跨空间起作用（Dyer, 1973；以及"单字母着色 / 空间线索可消除语义贡献"一类研究）。
- **预测**：见第 4 节 P1–P2。

### 2.6 两类顺序效应怎么处理

被试（和实验者）最先注意到的两个问题，都会污染 RT，必须同时处理：

1. **区组顺序**：整合段先做还是分离段先做，会带来练习/疲劳与策略迁移。
   - 按匿名编号的哈希在两个顺序之间平衡（`block_order` 记录在每次试次里）；
   - n=5 时无法严格对半，分析时可把顺序作为被试间变量做稳健性检查（结果页会显示每人的顺序）。
2. **按键顺序（手指与换手）**：D/K 是中指、F/J 是食指；食指更省力，中指更容易误按。当连续两个试次属于同一只手（如同为左手）时，只是换手指；属于不同手时，需要整只手切换，通常更慢。
   - **键位映射平衡**：两套左右镜像映射（A：红 D / 黄 F / 蓝 J / 绿 K；B：红 K / 黄 J / 蓝 F / 绿 D），按编号哈希分配，使"食指省力/中指费力"不固定绑在某几个颜色上；
   - **区组内过渡平衡**：40 个试次 = 39 次过渡，程序约束"换手"过渡落在 18–21 次之间（同手 18–21 次），使两种过渡在同一区组内大致各半；
   - **逐试次记录**：`map`、`hand`、`finger`、`prev_key`、`hand_switch` 都写进数据，结果页有「顺序与按键：平衡检查」表（每个条件的同手/换手试次数与平均 RT）；若两者差异大，说明按键转换是重要协变量，Stroop 效应仍按条件内平均计算。

### 2.7 分离显示会不会"太彻底"，被试根本没看见灰字？

这是设计里最需要正面回答的混淆，我的判断分三层：

1. **可见性不是主要问题**：灰字是 `#B0A795` 对 `#12100E`，对比度约 7.8:1，字号 104 px，且落在注视点上——它是可读的，不是"隐形"的。截图里也确实一眼能看到。
2. **注意分配才是真正的问题**：分离条件下任务相关的信息在色块上，灰字是任务无关的；被试可能"看见了但没有加工字义"。这与"词和颜色不再属于同一客体"是两回事，本设计无法把两者完全分开。这是**必须写进讨论**的混淆。
3. **数据里有内置检查**：如果灰字完全没被加工，分离条件的干扰应接近 0；若它仍有可靠的正干扰（P2），说明语义信息至少被部分加工了。因此结果页会把分离条件的干扰与它的 95% CI 单独列出——**干扰是否为 0 本身就是结果的一部分**，不需要额外的主观报告来"证明被试看见了"。

如果时间允许，更干净的对照是"第三种条件：高显著度的分离词"（把灰字换成浅色或加轮廓），看干扰是否随词的可加工性回升；本实验没有做，写进局限，也写进一页摘要的"改进与反思"。

## 3. 实验二：Cleveland–McGill 比例判断

### 3.1 出处

- Cleveland, W. S., & McGill, R. (1984). Graphical perception. *JASA, 79*, 531–554. 基本知觉任务层级：**位置（共同刻度）> 长度 > 角度/面积**。
- Hollands, J. G., & Dyre, B. P. (2000). Bias in proportion judgments: The cyclical power model. *Psychological Review, 107*, 500–524.
- Heer, J., & Bostock, M. (2010). Crowdsourcing graphical perception. *CHI '10*, 203–212.

### 3.2 条件与刺激

- 2（图形：饼图 / 条形）× 2（刻度：无 / 有），被试内，每格 10 试次，共 40。
- 比例池：**7, 10, 15, 22, 33, 40, 60, 68, 85, 92**；四个条件完全交叉（每个比例在每条件各出现一次），试次顺序随机。其中 **5 个是 5 的倍数、5 个不是**（每条件各 5/5，全实验 20/20）。
- 比例池刻意避开 25 / 50 / 75（防止刻度直接给出答案）。
- 为什么一半"整五"、一半"非整五"：如果真值全是 5 的倍数，被试会倾向凑整，整数答案容易偶然命中，误差被压低；如果全是小数，又会让任务变得不自然。一半一半既能抵消"凑整"的收益，又能直接比较两类真值的误差。
- 刻度：饼图在 25/50/75 处画三条短径向刻度（圈外、不标数字）；条形在 25/50/75 处画三条 1 px 竖线（不标数字）。
- 作答：拖动 0–100 滑块，**步长 1%**；按空格确认；无时间限制；记录作答 RT。
- **取整倾向的检查**：结果页报告「5 的倍数回答」的比例（随机作答的期望约 20%），并比较"整五真值"与"非整五真值"的 MAE。若整五真值的误差更小，说明凑整或刻度锚点帮了忙；若更大，说明凑整本身可能是偏差来源。这是描述性检查，n 小时只作参考。

### 3.3 指导语（要点）

> 判断铜色部分占整体的百分之多少；拖动滑块，空格确认；没有时间限制，尽量准确。有些图带刻度线，有些不带；一半左右的比例不是 5 的倍数，不必凑成 5 或 10 的倍数。

### 3.4 改进：加刻度线

- **理论**：C&M 的层级认为"共同刻度上的位置"是最精确的基本任务；角度/面积需要心算比例。加 25/50/75 刻度相当于把角度判断部分转成位置判断，提供参照锚点，预期降低误差；饼图（角度）应比条形（位置-长度）受益更大。
- **预测**：见第 4 节 P3–P5。

## 4. 预注册预测（收数前定稿）

> 这些预测在**收数之前**写入本文件与 `docs/预测.md`，并单独 commit（见 git log 中的 "预注册" 提交）。收数后不再修改方向与幅度，只在第 7 节报告结果。

| 编号 | 预测 | 检验方式 | 判定 |
|---|---|---|---|
| **P1** | 分离条件的 Stroop 干扰小于整合条件；预期整合 70–120 ms、分离 30–70 ms（下降 30%–60%） | 2×2 重复测量 ANOVA 的交互；配对比较「干扰(整合) − 干扰(分离)」的 95% CI 与 dz | 差值 > 0 且 CI 不覆盖 0 |
| **P2** | 分离条件的干扰**不为零**（语义冲突仍在） | 分离条件干扰的单样本检验 + bootstrap CI | CI 下限 > 0 |
| **P3** | 有刻度条件的判断误差小于无刻度（饼图预期 9–13 → 6–9 pp；条形 7–11 → 5–8 pp） | 配对比较 + 95% CI + η²p | 差值 > 0 且 CI 不覆盖 0 |
| **P4** | 刻度对饼图的帮助大于条形图（交互） | 2×2 交互项 | 交互 F 的 p < .05 且方向符合 |
| **P5** | 无刻度时小比例被高估、大比例被低估（β < 1）；有刻度时 β 更接近 1 | 周期幂模型 `ĵ = p^β/(p^β+(1−p)^β)` 拟合 | 比较 β 与 R² |

补充：

- **P6（探索）**：分离条件整体 RT 可能略慢（判断对象变成色块），但正确率不低于整合条件。
- **P7（探索）**：比例判断的误差随真实比例呈"两端大、中间小"的形态（角度/长度判断的经典模式）。

### 4.1 分析计划

- 只用正式试次；练习、抢按（<150 ms）、超时、错误试次不进入 RT 分析。
- 被试层面：正确率 < 70% 标注「低质量」但仍保留在数据里，分析时单独报告。
- 效应量：配对 dz；95% CI 用 10,000 次按被试重抽的 bootstrap；方差分析报告 η²p。
- 样本量：每个实验目标 ≥ 5 名他人；被试可只做一个实验，也可两个都做。n 很小，**以 CI 与个体数据为主**，p 值只作参考，讨论中明确说明功效不足。
- 两个主检验（P1、P3）不做多重校正，其余为次要/探索性分析，全部结果都会报告。

## 10. Known limitations

- **分离条件的双重混淆**：分离条件同时改变了"词的颜色（变灰）"与"注意对象（字→色块）"，干扰下降不能单独归因于客体整合；若分离条件的干扰接近 0，也无法区分"没有整合"与"字没被加工"。这是本设计最重要的局限，讨论里必须正面写。
- **按键与顺序**：虽然做了镜像映射与换手过渡平衡，n=5 时无法做到完全对半；顺序效应只能被"平衡 + 记录 + 事后检查"，不能被完全消除。
- 比例判断的滑块初值固定为 50，可能带来轻微锚定；
- EZ-DDM 用每个条件的汇总正确率与 RT 矩反解，是近似拟合，不做个体层面模型比较；
- 结果页的 2×2 ANOVA 假设球形性（2×2 时仅一个交互自由度，球形性自动满足）；
- n 很小，所有推断都应视为探索性。
