# 好球还是坏球？

**棒球主审判定中的信号检测论 · 交互式实验**

信号＝好球（球经过好球区）｜噪声＝坏球（球没有经过好球区）

---

**双击 `index.html`。**

## 二、怎么玩

| 操作 | 按键 |
|---|---|
| 判**坏球**（Ball） | `A` 或 `←`，或点左侧按钮 |
| 判**好球**（Strike） | `D` 或 `→`，或点右侧按钮 |
| 信心评级（仅开启"信心评级"模式时） | `1` / `2` / `3` / `4` |

一次投球的流程：

```
准备（投手蓄力，800ms）
  → 球飞向本垒板（450ms，带运动拖影）
    → 球穿过好球区，判定倒计时开始（默认 1500ms，画面下方有限时条）

```

每局开始有 **5 个练习球**（更容易，不计入统计）。

## 三、规则：擦到就算好球

棒球规则原文是 *any part of the ball passes through any part of the strike zone* ——
**球的任何一部分经过好球区的任何一部分，就是好球**。所以球心在好球区外、
但球体压到线（甚至只是相切），仍然算好球。

真实棒球里的好球区是一个**三维立体区域**（本垒板上方的一根"柱子"）。本实验
按规模把它简化为**一个平面**（球穿过本垒板前缘平面时的截面）。简化之后，
"球经过好球区"就等价于平面上"圆盘与矩形相交"，也就是：

```
球心到好球区矩形的最短距离  ≤  球半径（1.45″，球直径约 2.9″）
```

画面上因此**只有好球区这一条白线**：

| 线 | 含义 |
|---|---|
| **好球区** | 宽 **17″**（= 本垒板宽），高 **0.115 × 打者身高(cm)**，白色实线 |

判据是**球有没有碰到这个框**，而不是球心落在哪里。反馈阶段会把**整颗球**画在它
真实的位置，所以"擦到即好球"是一眼就能看出来的 —— 不需要（也不应该）再画一条
抽象的"球心判定线"，那只会让画面变乱、让人误以为要判断的是球心。

程序内部仍会做一次等价换算（把矩形向四周外扩一个球半径 → 球心落在这个外扩区域内
就是好球）来生成试次和反推 σ，但这条内部边界**不画出来**。这样做的结果是：
判定规则完全忠实于规则原文，而 ε 仍然是一个标量，`d′ = 2ε/σ` 的推导不受任何影响。

好球区高度系数 0.115 in/cm 的来源：MLB Statcast 平均 `sz_bot ≈ 19.2″`、
`sz_top ≈ 41″`（对应约 188 cm 打者 → 好球区高 ≈ 21.8″），21.8 / 188 ≈ 0.116。
打者身高可在 170–195 cm 之间切换，好球区高度随之变化（19.55″–22.43″）。

### 只投"擦边球"

正中好球区或明显偏低的球不构成检测问题，谁都不会判错，测得的信息量为零。
所以本实验只投**球边离好球区线 ±3″ 以内**的球 —— 这也正是真实棒球里最常发生
争议的"压线球"（on the black）。

## 四、四种结果

| | 真实是好球（信号） | 真实是坏球（噪声） |
|---|---|---|
| **你判好球** | **命中 Hit** ✅ 判对了，投手得利 | **虚报 FA** ❌ 误判好球，打者被冤枉，**可能直接被三振** |
| **你判坏球** | **漏报 Miss** ❌ 漏判好球，投手白投一个好球 | **正确拒绝 CR** ✅ 判对了，坏球数 +1 |

注意 **FA 与 Miss 的代价并不对称**：一次误判好球可能直接造成三振出局且不可逆，
而漏判只是让投手少得一个好球。这就是真实比赛里"投手友好／打者友好"倾向有理性
基础的来源，也是本实验用来改变被试判断标准的场景动机。

## 五、难度是怎么操纵的

### 5.1 界面上的"难度"控制的是物理量 ε

设置里的"难度"控制的是**球边到好球区线的那一小段距离 ε（英寸）**，**不是**让被试
直接选一个 d′。d′ 一律由实际成绩事后算出。

| 等级 | ε | 直观参照 | 理想上限 2ε/σ |
|---|---|---|---|
| L1 极明显 | 3.0″ | 约一个球直径 | 6.0 |
| L2 明显 | 2.0″ | 约 2/3 球直径 | 4.0 |
| **L3 基准（默认）** | **1.0″** | **约 1/3 球直径** | **2.0** |
| L4 困难 | 0.6″ | 约 1/5 球直径 | 1.2 |
| L5 极限 | 0.3″ | 极微小的偏差 | 0.6 |

每一球的 ε 还会在基准值 ±20% 内浮动，避免被试记住固定的偏移量。

### 5.2 心理量模型

被试无法直接读到球的真实位置，他得到的是一个**带噪声的内部估计** ŷ：

```
ŷ = y_true + 噪声                y_true = 球边到好球区线的符号距离（向内为正）
信号试次：y_true = +ε            噪声试次：y_true = −ε
判定规则：ŷ > k 时判好球（k = 被试设定的判断标准）
```

由正态模型直接推出：

```
P(Hit) = Φ((ε − k) / σ)
P(FA)  = Φ((−ε − k) / σ)

d′ = z(P(Hit)) − z(P(FA)) = 2ε / σ        ← 只与 ε 和 σ 有关，与判断标准 k 无关
c  = −½[z(P(Hit)) + z(P(FA))] = k / σ     ← 只与判断标准有关
β  = exp(d′ × c)
```

两条可检验的性质，正是本实验要展示的：

1. **d′ 只随 ε 变，不随执法风格变**：同一难度下无论偏严还是偏松，d′ 应基本不变。
2. **由实测 d′ 反推噪声**：`σ_总 = 2ε / d′`。

### 5.3 外部噪声 σ：为什么球的位置会有一点点"晃"

如果画面是像素完美的，被试的知觉噪声会趋近于 0、d′ 冲到天上，实验完全失去
测量能力。所以程序按心理物理学的**外部噪声范式**（Lu & Dosher, 1998），
在每一球给球的**显示位置**叠加一个已知大小的随机偏移：

```
2D 显示位置 = 真实位置 + N(0, σ_ext²)          σ_ext = 1.0 英寸（配置项 externalNoiseIn）

σ_总² = σ_ext² + σ_自己²
d′_上限 = 2ε / σ_ext                            （理想观察者，σ_自己 = 0）
实测 d′ ≤ 上限，σ_总 = 2ε / d′
σ_自己 = sqrt(max(0, σ_总² − σ_ext²))           ← 剥离外部噪声后的"被试自己的"知觉噪声
```

**σ_自己是无法直接观测、只能由 d′ 反推出来的心理量** —— 这正是信号检测论
作为测量工具的价值所在。外部噪声是"被试自己也不知道"的那种噪声：反馈里**不显示**
它挪动了多少（反馈只把球画在真实位置），但它的影响已经包含在实测 d′ 里，
所以能够被反推出来。

三处实现细节决定了数学是否干净：

1. 外部噪声是**每试次抽取一次并固定**的随机偏移，**不是**逐帧抖动。
   逐帧抖动会被视觉系统在时间上平均掉，无法有效提高 σ。
2. 因此显示位置的方差**恰好**等于 σ_ext²，没有被别的东西污染。
3. 球的柔边是固定 2px 的渲染细节，各难度一致，定位不确定度约 0.15″，
   相对 σ_ext = 1.0″ 只有约 2% 的方差贡献，可忽略。

### 5.4 沿边界采样的内缩量 = 3σ_ext

每个试次只有一条"参照边界"，但球在垂直于该边界的另一个坐标上仍可能靠近相邻
边界。若内缩量太小，1″ 的显示噪声就足以把球推到相邻边界之外，这个试次就变成
真正意义上"跨两条边界的模糊试次"，会把无关的混淆混进 d′。

因此内缩量设为 **3.0 英寸 = 3σ_ext**，把这种污染的概率压到约 0.1% 以下。

## 六、指标与公式

```
H  = 真好球 且 判好球          FA = 真坏球 且 判好球
M  = 真好球 且 判坏球          CR = 真坏球 且 判坏球
（N_S = H + M，N_N = FA + CR，均为剔除超时后的有效试次）

P(Hit) = H / N_S        P(FA) = FA / N_N
正确率 = (H + CR) / (N_S + N_N)

d′ = z(P(Hit)) − z(P(FA))
c  = −½ [ z(P(Hit)) + z(P(FA)) ]          c > 0 = 保守（偏向判坏球）
β  = exp(d′ × c)
```

> **c 的方向约定**（最容易讲反的一点）：标准 SDT 约定 **c > 0 表示保守**，
> 即偏向报告"无信号"。本场景中"是"= 判好球，所以 **c > 0 = 倾向判坏球
> = 打者友好／严抓**。结果页会直接把这个方向写出来。

### 6.1 0/1 极端比例的修正

当 P(Hit) = 1 或 P(FA) = 0 时 `z(1) = +∞`、`z(0) = −∞`，d′ 直接发散。
本实现默认使用 **Hautus (1995) 对数线性修正**：

```
P(Hit) = (H + 0.5) / (N_S + 1)
P(FA)  = (FA + 0.5) / (N_N + 1)
```

结果页提供下拉框，可随时切换为 `1/(2N)` 修正或不修正，直接对比差异
（自检脚本里有一个 20/20 全对的例子：对数线性修正给出 d′ = 3.96，
`1/(2N)` 给出 3.92，不修正则被兜底但仍高达 9.51）。

### 6.2 两个数学函数（均手写，无外部库）

| 函数 | 算法 | 精度 |
|---|---|---|
| `z(p)` = Φ⁻¹(p) | Wichura (1988) Algorithm **AS 241**（R 语言 `qnorm` 所用算法） | 相对精度约 1e-15；`z(0.5)` **精确**返回 0 |
| `Φ(x)` / `erfc(x)` | Numerical Recipes §6.2 的 Chebyshev 拟合 | 绝对误差 < 1.2e-7 |

选择 AS 241 而不是"Acklam 近似 + 迭代精修"，是因为 AS 241 不依赖 Φ 自身的精度，
在 p = 0.5 处精确返回 0（Acklam + Halley 方案会继承 Φ 的 1.5e-8 误差）。

## 七、超时的球怎么算

标准 SDT 要求每个试次都有二择一反应，超时试次在数学上无法归入 2×2 表。本实现：

- 超时单独记为**「未响应」**，默认**从 SDT 计算中剔除**，只报告**超时率**；
- 配置项 `timeoutPolicy` 可切换为 `asNo`（把超时按"判坏球"计入 Miss 或 CR）；
- 默认判定限时为较宽松的 1500 ms，确保超时率通常很低。

> 若直接把超时算作"判坏球"，会人为抬高 P(Miss) 与 P(CR)、压低 P(Hit)，
> 把**反应速度**的差异错误地算进 **d′** 里。

## 八、参数选择的理由

| 参数 | 默认值 | 为什么 |
|---|---|---|
| 每局投球数 | **40** | 20 球且 P(S) = 0.5 时只有 10 个信号试次，`P(Hit)` 的最小刻度就是 0.1，估出的 d′ 标准误可达 **±0.5 甚至更大** —— 不同难度之间的差异会被噪声吞掉。40 球时（20 个信号试次）d′ 标准误降到约 ±0.3；60 球约 ±0.25。界面上 20 球那一项标注了"不推荐"。 |
| 练习球 | 5 | 让被试先建立判断标准；练习数据被标为 `practice`，不进入 2×2 表。 |
| 只投擦边球 | ±3″ | 见 §3。 |
| 判定限时 | 1500 ms | 真实 MLB 主审的判断窗口更短，但过短会大量产生超时、把速度因素混进 d′。1500 ms 兼顾"限时"与"数据可用"。 |
| 投球飞行时间 | 450 ms | 对应 MLB 均速 93 mph 跨越 18.44 m 的 0.43 s。 |
| σ_ext | 1.0″ | 让默认难度 L3（ε = 1.0″）的 d′ 上限落在 2.0 —— 既不是天花板（>4）也不是瞎猜（<0.5）。 |
| 沿边界内缩 | 3.0″ = 3σ_ext | 见 §5.4。 |
| ε 浮动 | ±20% | 避免被试记住固定偏移量；幅度小，不会显著改变该等级的 d′。 |
| 打者身高 | 180 cm | 可在 170–195 cm 间切换，好球区高度按人体测量比例变化。 |

## 九、d′–ε 回归：把不可观测的心理量反推出来

SDT 预测 `d′ = (2/σ)·ε`，即一条**过原点**的直线。用最小二乘拟合过原点直线的斜率
`b = Σ(εᵢ·d′ᵢ) / Σ(εᵢ²)`，则：

```
σ_总 = 2 / b
σ_自己 = sqrt(max(0, σ_总² − σ_ext²))
```

**用法：把同一套条件（执法风格、P(S)、打者身高都相同）下不同难度各跑一局**，
结果页第三张图就会画出散点与回归线，并直接标出反推出的 σ_总、σ_自己 与 R²。

这是本实验最有分量的结果：物理上只操纵了 ε，心理量 σ 是算出来的。
相比只报一个 d′ 数字，"实测 d′ 与 ε 呈过原点线性关系"是对 SDT 模型的直接检验，
也能顺便验证实验程序本身是否可靠。

## 十、ROC 曲线的两种模式

| 模式 | 做法 | 优点 | 代价 |
|---|---|---|---|
| **模式 A：单局信心评级法** | 每球二择一后追加一个 4 级信心评级（1 肯定坏球 / 2 像坏球 / 3 像好球 / 4 肯定好球），用三个累计切点（≥4、≥3、≥2）算出 3 个 (P(FA), P(Hit)) 点 | **一局就能画出 ROC**（约 3 分钟） | 每球多一次按键 |
| **模式 B：多局不同判断标准** | 固定同一难度，依次跑「打者友好 / 中立 / 投手友好」三局，每局一个点 | 每局都是纯二择一，手感最顺 | 需要跑 3 局（约 8 分钟） |

两种都已实现，可在"更多选项"里选择。结果页会把实测点叠在**理论 ROC**
（`P(Hit) = Φ(d′ + z(P(FA)))`）上直接对照，并给出经验 AUC。

> 注意：一条经验 ROC 必须用两个极端切点闭合 —— 判据最严时 (0, 0)（从不判好球），
> 判据最松时 (1, 1)（总是判好球）。`SDT.math.auc()` 会自动补上这两个端点，
> 否则算出来的只是"部分面积"，是个没有意义的数值。

### 10.1 模式 B 的刺激复用

用模式 B 时，**只改执法风格、其它条件都不变**，程序会**自动复用上一局的随机种子**，
也就是让两局面对**完全相同的一批球**（同样的 ε、同样的真实位置、同样的显示噪声），
只有判断标准在变。结果页会明确写出"本局复用了上一局的刺激序列（种子 xxx）"。

为什么必须这样：如果每局都重新随机生成球的位置，两局之间 (P(FA), P(Hit)) 的差异
就既包含判断标准的效应，也包含抽样波动，把这些点连成 ROC 就是把噪声当成效应。

程序还会在收集模式 B 的 ROC 点时**按随机种子分组**，只取局数最多的那一组，
避免把不同刺激序列下的局混进同一条曲线。

## 十二、为什么双击就能跑

助教会 clone 之后**双击 `index.html`**。以下三件事在 `file://` 协议下会直接崩掉，
本项目全部避开：

| 陷阱 | 后果 | 对策 |
|---|---|---|
| `<script type="module">` / `import` | CORS 错误，脚本全部不执行 | **全部使用传统 `<script src>`**，每个文件用 IIFE 隔离，只挂 `window.SDT` |

| 引用外部 CDN（Chart.js 等） | 断网或墙掉就白屏 | **零外部依赖**，三张图全部 Canvas 手绘 |

其他 `file://` 细节也已处理：`devicePixelRatio` 缩放避免高分屏模糊；
CSV 下载用 `Blob + URL.createObjectURL + <a download>`（`file://` 下可用）。

## 十四、已知局限

1. **三维好球区简化为平面**：真实好球区是本垒板上方的一个立体区域，球可能从
   侧上方斜插进来。本实验只取球通过本垒板前缘平面时的截面，因此"球的一部分越过
   好球区"在纵深方向上的情形没有建模。
2. **平面内的球按圆盘处理**：严格实现需要判断球体与三维区域的相交，当前是
   平面内圆盘与矩形的相交判定 —— 这正是"擦到即好球"在二维下的等价形式。
3. **二维判断的真实性**：主审实际要同时判断水平与垂直两个方向。本实验生成试次时
   让球明确归属某一条边界（并用 3σ 内缩排除角上歧义），以便"垂直 vs 水平"的
   分组比较干净；代价是损失了"角上球"这一类真实情形。
4. **只有视觉通道**，未实现听觉或触觉变体。
5. **单被试设计**：程序只记录本人成绩，未做多被试汇总（可由导出的 CSV 汇总）。
6. **未做试次间的随机化约束**（如信号试次不连续超过 3 次），当前只保证总体计数
   精确与边界均衡。
7. **未实现 d′ 的置信区间**：可加入基于二项分布的 bootstrap 让"多局平均"有误差棒。
8. **未做无反馈对照组**：当前固定为"每球后立即反馈"，如需可加开关做成组间比较。

## 十六、常见问题

**Q：好球区的边界是客观确定的（甚至还有鹰眼回放），这算"感觉阈限"问题吗？**
A：SDT 的适用范围不限于生理感觉阈限。任何"世界真实状态二分 + 观察者只能依据
带噪声的内部表征做二分判断"的情形都适用（Green & Swets 之后的信号检测论已推广到
记忆、医学诊断、工业质检、告警系统）。本场景中噪声来源明确且真实：球以约 93 mph
飞行 18.44 m 仅约 **0.43 秒**，主审在此期间还要处理球的纵向位移、捕手的接球动作与
framing、自身视线被遮挡等因素，其内部估计必然带噪。而且本实现把物理操纵量固定为
ε、把噪声显式建模为 σ（并且注入了一个**已知大小**的外部噪声 σ_ext），模型是可检验的
（d′ 与 ε 的线性关系、d′ 与执法风格无关），比单纯说"有误差"严格得多。

**Q：为什么不用 2AFC？**
A：真实主审面对的是单次呈现的 yes/no 判断，没有第二次比较的机会，因此 yes/no
与场景一致。若改成 2AFC，d′ 会变成 √2 倍，需要另外说明。

**Q：为什么显示端要加噪声？那不是作弊吗？**
A：恰恰相反，这是**标准的外部噪声范式**。像素完美的显示会让 σ 趋近 0、d′ 冲到天上，
实验完全失去测量能力。加入**已知大小且被试无法归因**的外部噪声之后，
`σ_总² = σ_ext² + σ_自己²` 可以解出被试自身的 σ_自己。这正是现代心理物理学测量
内部噪声的常规做法（Lu & Dosher, 1998）。

**Q：d′ 为什么比理论上限低？**
A：理论上限 `2ε/σ_ext` 是**理想观察者**（σ_自己 = 0）的值。实测 d′ 一定更低，
因为被试自身的知觉噪声会叠加进来。真正有意义的检验是 **d′ 对 ε 的回归是否线性
且过原点**（结果页第三张图）。

**Q：P(Hit) = 1 的时候 d′ 为什么不是无穷大？**
A：因为做了 Hautus (1995) 对数线性修正 `P = (count + 0.5)/(N + 1)`。
结果页可以一键切换成"不修正"，直接看到 d′ 变成 9.51 这种数值。

**Q：超时的球怎么算的？**
A：单独计为"未响应"并默认从 2×2 表中剔除，结果页报告超时率（见 §7）。

**Q：三档执法风格下 d′ 为什么应该不变？**
A：这是 SDT 的**可分离性假设**：d′ 反映分辨力（由 ε 与 σ 决定），c 反映判断标准
（由 payoff / 先验决定），二者理论上独立。实测中 d′ 在三档间基本持平、而 c 显著移动，
就是对模型的直接支持。
