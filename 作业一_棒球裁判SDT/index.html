这个实验在测什么？

信号与噪声

信号 = 好球：球经过好球区。噪声 = 坏球：球没有经过好球区。

怎么玩：球从投手丘飞来。穿过好球区后，你必须在 1500 毫秒内作出判罚 —— 按 D 或 → 判好球， 按 A 或 ← 判坏球，也可以直接点画面下方的两个按钮。 每一球结束后会立刻告诉你球的真实位置与对错。

你只看到球飞过本垒板的一瞬间，然后必须做出二择一判断。因为球速很快、 落点又压在边线上，你的知觉必然带有不确定性 —— 这正是信号检测论要测量的东西： 你分辨好坏球的能力（d′），以及 你判罚的松紧倾向（c）。这两件事是相互独立的。

判定规则：擦到就算好球

棒球规则原文是 any part of the ball passes through any part of the strike zone ——球的任何一部分经过好球区的任何一部分，就是好球。所以球心在好球区外、 但球体压到线（甚至只是相切），仍然算好球。

真实棒球里的好球区是一个三维立体区域（本垒板上方的一根"柱子"）；本实验按规模 把它简化为一个平面（球穿过本垒板前缘平面时的截面）。简化之后， "球经过好球区"就等价于平面上"圆盘与矩形相交"，也就是

球心到好球区矩形的最短距离 ≤ 球半径　　 （球半径 1.45″，球直径约 2.9″）

画面上只有好球区这一条白线（宽 17″ = 本垒板宽，高 = 0.115 × 打者身高 cm）。 判据是球本身有没有碰到这个框，不是球心落在哪里 —— 所以反馈时会把整颗球 画在它真实的位置，擦没擦到一眼就能看出来。

难度 ε 是什么意思

ε 就是球边到好球区线的那一小段距离，反馈时会用一条短粗线直接标出来：

  • 好球试次：球边压过了线 ε（压线深度）；
  • 坏球试次：球边离线的空隙是 ε。

为什么只投擦边球

正中好球区或明显偏低的球不构成检测问题，谁都不会判错，测得的信息量为零。 所以本实验只投球边离好球区线 ±3″ 以内的球 —— 这也正是真实棒球里最常发生 争议的"压线球"。

难度是怎么设定的？为什么球的位置会有一点点"晃"？

难度 ε = 球边到好球区线的距离

设置里的"难度"控制的是一个物理量 ε：球边到好球区线的那一小段真实距离（英寸）。 它不是让你直接选一个 d′ —— d′ 一律由你的实际成绩事后算出来。

外部噪声 σ

如果画面是像素完美的，你的知觉噪声会趋近于 0、d′ 冲到天上，什么也测不出来。 所以程序在每一球给球的显示位置叠加了一个已知大小的随机偏移 σ （表现为"球在动、落点看不准"）：

σ总² = σ外部² + σ自己²　　d′上限 = 2ε / σ外部　　 σ自己 = √(σ总² − σ外部²)

σ外部 = 1.0″ 是程序注入的、你无法归因的噪声。由你的成绩反推出来的 σ自己 才是你自己的知觉噪声 —— 一个无法直接观测、只能算出来的心理量。 反馈阶段会把"球的真实位置"和"你实际看到的位置"同时画出来，你能亲眼看到它把球挪了多远。

方法与公式

指标

  • P(Hit) = H / (H + M)，P(FA) = FA / (FA + CR)
  • d′ = z(P(Hit)) − z(P(FA))
  • c = −½ [ z(P(Hit)) + z(P(FA)) ]　　c > 0 表示保守，即偏向判坏球
  • β = exp(d′ × c)
  • 正确率 = (H + CR) / (H + M + FA + CR)

0 / 1 极端比例的修正

当 P(Hit) = 1 或 P(FA) = 0 时 z 值为 ±∞，d′ 会发散。默认使用 Hautus (1995) 的对数线性修正 P = (count + 0.5) / (N + 1)，结果页可切换为 1/(2N) 修正或不修正，直接对比差异。

超时的球怎么算

限时内没有按键的球在数学上无法归入 2×2 表，默认单独记为"未响应"并从 d′ 的计算中剔除，只报告超时率。若把超时当成"判坏球"，会把反应速度的差异 错误地混进 d′ 里。

z(p) 与 Φ(x) 的实现

z(p) 采用 Wichura (1988) 的 Algorithm AS 241（即 R 语言 qnorm 所用算法）， 相对精度约 1e-15；Φ(x) 采用 Numerical Recipes §6.2 的 erfc 切比雪夫拟合， 误差小于 1.2e-7。两者均手写，不依赖任何外部库。

为什么要注入外部噪声

这是心理物理学中的外部噪声范式（Lu & Dosher, 1998）。像素完美的显示会让 被试的内部噪声 σ 趋近于 0、d′ 冲到天上，实验失去测量能力。注入一个已知大小、 被试无法归因的外部噪声之后，σ总² = σ外部² + σ自己² 就可以解出被试自身的 σ自己，这正是现代心理物理学测量内部噪声的常规做法。
