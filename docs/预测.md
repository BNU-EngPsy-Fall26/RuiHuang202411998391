## 1. 要检验什么

两个经典注意实验各加入一个**原版之外的新条件**，用同一批被试的数据检验这个条件是否改变了表现：

| | 原版条件 | 新增条件 | 理论依据 |
|---|---|---|---|
| Stroop | 整合显示（颜色涂在字上） | **分离显示**（灰词 + 上方独立色块） | 语义冲突 vs 客体整合（Dyer, 1973） |
| 比例判断 | 无刻度 | **25/50/75 刻度** | 位置判断优于角度判断（Cleveland & McGill, 1984；Hollands & Dyre, 2000） |

---

## 2. 预测

### P1（主检验）分离显示降低 Stroop 干扰

- **方向**：干扰(分离) < 干扰(整合)。
- **幅度**：整合条件预期 70–120 ms；分离条件预期 30–70 ms；相对下降 30%–60%。
- **检验**：2（一致性）× 2（显示）重复测量 ANOVA 的交互项；配对比较「干扰(整合) − 干扰(分离)」。
- **判定**：差值 > 0，且按被试 bootstrap 的 95% CI 不覆盖 0；同时报告 dz。
- **若结果为否**：说明干扰不依赖"词与颜色同属一个客体"，语义冲突可跨空间起作用——这本身是关于 Stroop 机制的有信息量的结论。

### P2 分离条件的干扰不为零

- **方向**：分离条件仍存在 > 0 的干扰。
- **幅度**：预期 30–70 ms，明显小于整合条件但大于 0。
- **检验**：分离条件干扰的单样本检验 + bootstrap 95% CI。
- **判定**：CI 下限 > 0。

### P3（主检验）刻度降低比例判断误差

- **方向**：MAE(有刻度) < MAE(无刻度)。
- **幅度**：饼图 9–13 → 6–9 个百分点；条形 7–11 → 5–8 个百分点。
- **检验**：配对比较（按被试）+ 95% CI；2×2 ANOVA 的刻度主效应。
- **判定**：差值 > 0 且 CI 不覆盖 0。

### P4 刻度对饼图的帮助大于条形图

- **方向**：MAE 下降幅度（无刻度 − 有刻度）：饼图 > 条形图。
- **幅度**：预期饼图下降 2–5 pp，条形下降 0.5–3 pp，差值 ≥ 1 pp。
- **检验**：2（图形）× 2（刻度）交互项；报告 η²p 与配对比较。
- **判定**：交互方向符合且 p < .05；若只看到主效应而无交互，按"刻度对两种图形都有帮助"报告。

### P5 无刻度时存在系统性偏差，刻度使其变小

- **方向**：周期幂模型 `ĵ = p^β / (p^β + (1−p)^β)` 中，无刻度条件 β < 1（小比例被高估、大比例被低估）；有刻度条件 β 更接近 1。
- **检验**：对每个条件的（真实比例，平均判断值）拟合 β；比较 β 与 R²；用个体层面拟合的 β 分布作稳健性检查。
- **判定**：β(无刻度) < 1 且 β(有刻度) > β(无刻度)。

### P6（探索）分离条件整体更慢

- **方向**：分离条件整体 RT 略高于整合条件（判断对象从"字"变为"色块"）。
- **判定**：只报告效应量与 CI，不作强推断。

### P7（探索）比例误差呈两端大、中间小

- **方向**：|误差| 在接近 0% 与 100% 的比例上更大。
- **判定**：描述性报告（按真实比例分箱的 MAE），不设显著性判定。

## 3. 分析计划（收数前写定）

1. **样本**：每个实验至少 5 名他人；被试可只做一个实验，也可两个都做（同一匿名编号）。
2. **纳入**：正式试次；Stroop 只分析正确且 150 ms ≤ RT ≤ 2500 ms 的试次；比例判断分析全部正式试次（无论误差大小）。
3. **剔除**：练习、抢按、超时不计入 RT；被试正确率 < 70% 标注"低质量"但仍保留并单独报告，不静默删除。
4. **效应量**：配对 dz；95% CI 采用 10,000 次按被试重抽的 bootstrap；方差分析报告 η²p。
5. **推断**：n 很小，以 CI 与个体数据为主；p 值只作参考，讨论中明确说明功效不足。
6. **多重比较**：两个主检验（P1、P3）各自独立报告，不作校正；P4–P7 为次要/探索性分析，全部结果报告，不挑选显著的结果。
7. **模型**：Stroop 用 EZ-DDM（Wagenmakers et al., 2007）按条件反解 v / a / Ter 并模拟 RT 分布；比例判断用周期幂模型（Hollands & Dyre, 2000）拟合 β。
8. **与原文对比**：Stroop 对比 1935 年的 +470 ms/项（+74.3%），只比方向与比值；比例判断对比 C&M 的任务层级（位置 > 长度 > 角度/面积），不比绝对值（误差口径不同）。
